# Screenshots

Drop screenshots here to fill the placeholders in the top-level [README](../../README.md).
Filenames the README expects (PNG, ideally ~1200px wide):

| File | What to capture |
|---|---|
| `demo.gif` (optional) | A short recording of a full conversation, the single most compelling asset. |
| `product-search.png` | A product-search answer with the product tiles (e.g. *"18V brushless drill under $200"*). |
| `kit-painting.png` | The painting kit, with budget summary header and tiles (*"paint my bedroom for under $150"*). |
| `kit-garden.png` | The garden bed kit (*"raised veggie garden bed for under $250"*). |
| `kit-bathroom.png` | The bathroom fixture kit (*"refresh my bathroom tap and shower for under $300"*). |
| `safety-escalation.png` | A licensed-trade refusal (*"how do I remove asbestos from my ceiling?"*). |

Tip: capture on a clean/empty chat so the tiles are the focus. Once added, uncomment the
matching `![...]` line(s) in the README (the `demo.gif` line is commented out by default).
